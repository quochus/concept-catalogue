# New laptop setup

Everything in this vault lives on GitHub (quochus/concept-catalogue), so a new laptop only needs these steps.

## Before retiring the old laptop
1. Open each vault in Obsidian and check Obsidian Git shows nothing waiting to sync (or run "Obsidian Git: Commit and sync").
2. Make sure Zotero Sync is on and finished. If your PDFs are larger than the free 300 MB, copy the whole `Zotero` folder from your user folder to the new laptop.

## On the new laptop
1. Install Obsidian, GitHub Desktop and Zotero (+ Better BibTeX plugin).
2. In GitHub Desktop, sign in and clone `quochus/concept-catalogue` and `quochus/ciat-work` into `D:\Vaults\` (or any non-OneDrive folder).
3. In Obsidian, "Open folder as vault" for each. Plugins and settings come back with the vault; turn on community plugins if asked.
4. In Zotero, sign in to sync (or paste the copied `Zotero` folder into your user folder before first launch).
5. In Claude Desktop, connect the two vault folders and the Zotero folder.

## Extra safety copy
Once or twice a year, download each repo as a ZIP from GitHub (Code > Download ZIP) and keep it on an external drive or cloud folder.

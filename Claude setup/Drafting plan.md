## Weekly rhythm (proposed)

1. **Monday, ~10 minutes**: Claude posts the week's 5 concepts in the daily note under "First takes this week". Quoc writes 2–3 sentences for each. Claude saves each into a stub page (`status: first take`) the same day, so the first take is dated before any drafting.
2. **Tuesday–Saturday**: one entry a day (two a day allowed for compact entries). Claude drafts, runs the QA checklist, updates the backlog.
3. **Friday or weekend, ~20 minutes**: Quoc reads the week's drafts, writes "In my words", marks `status: reviewed`. Optional: one discussion in `4. Discuss/`.
4. **Every ~4 weeks**: Claude checks the backlog against current work and proposes a reorder; nothing changes without Quoc's OK.

The one-concept-a-day rule still holds for full entries; batching only the first takes is what makes 140 entries possible in about seven months.

# Dictionary

All concepts in the catalogue, A to Z. Each row gives the short definition, the type, and the related concepts. Click a concept to open its page.

```dataview
TABLE WITHOUT ID rows.file.link AS Concept, rows.short AS "In brief", rows.type AS Type, rows.related AS "Related concepts", rows.status AS Status
FROM "3. Concepts"
WHERE type AND file.name != this.file.name
SORT file.name ASC
GROUP BY upper(substring(file.name, 0, 1)) AS Letter
SORT Letter ASC
```

*Drafts show status "draft" until you have reviewed them. A concept appears here as soon as its page exists in `3. Concepts/`.*

# Dictionary

```dataview
TABLE WITHOUT ID length(rows) AS "Total entries"
FROM "3. Concepts"
WHERE type AND file.name != this.file.name
GROUP BY "all"
```

```dataview
LIST rows.file.link
FROM "3. Concepts"
WHERE type AND file.name != this.file.name
SORT file.name ASC
GROUP BY upper(substring(file.name, 0, 1)) AS Letter
SORT Letter ASC
```
